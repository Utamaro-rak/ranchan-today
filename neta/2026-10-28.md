## 1. 「疲れた脚で走る」を鍛える: ステーション直後のランこそ練習すべき本体、最も効くのはスレッドプッシュ→Run 3とランジ→Run 8のペア

- HYROXのランはすべて「ステーション直後のラン」であり、フレッシュな脚の5kmタイムはそのまま転移しない、というのが Compromised Running（疲労下ラン）の考え方。エリートは Run 1→Run 8 の落ち幅を1kmあたり15秒以内に抑えるが、20秒を超えると「最初のランが速すぎた」サインとされる。後半（Run 5〜8）のほうがフィニッシュタイムとの相関が強い。
- ステーションごとにランへの影響が違う。スレッドプッシュ後の Run 3 は「最初に本当に醜くなるラン」、サンドバッグランジ後の Run 8 は「最もきつい1km」になりやすく、この2ペアを最優先で練習すべきとされる。逆に SkiErg 後は脚がほぼ残っており、飛ばしすぎに注意。
- 練習法はフルシミュレーションではなく「ペアの繰り返し」: スレッドプッシュ20〜40m（または重いウォーキングランジ）→400〜800mをレースペースで4〜6本、ウォールボール20〜30球→400〜1,000m、ロウイング500m→400〜1,000m、ファーマーズキャリー100〜200m→400〜1,000m。間は2分歩き、週1回、レース前1か月は週2回が目安。4週間プランでは、週ごとに本数・距離・重量を段階的に上げる。
- 駅直後の最初の300mの処方箋も具体的: ストライドを短く刻む、200〜300mは時計を見ない、意識的なゆっくりした吐息で心拍を落とす、半分あたりでリズムが戻るのを待つ。効果測定は「フレッシュな1km」と「スレッド50m直後の1km」の差（＝Compromised Cost）を4週間ごとに測り、その差の縮小を追う。
- 日記での使いどころ: Day046の「ワーク直後のラン初動の遅さ」という本人の課題に直結する、練習メニュー回に使える。10/27の第5項（スレッド・ウォールボールのペーシング）・第6項（週2セッションの振り向け）とは別角度で、「走る練習」ではなく「疲れた状態から走り出す練習」という切り口で書ける。ランちゃんの「量ではなく中身」とも響く。

## 2. 28万人デビューのデータ: Roxzoneは「歩かずジョグで通る」だけで7〜8分違う、2つの壁は Run 1→2 と Run 7→8（使用済み：Day076）

- 公開リーダーボードから集めた初出場28万人超の分析。Open Male の Roxzone（遷移合計）は、60分切り層で平均4:19に対し、110分超層では12:02と約7〜8分の差がある。Roxzoneに時計表示がないため、初出場者は歩いて休み、水分補給で漂い、気づかぬうちに88分のレースを95分にしてしまう、と指摘されている。対策はただひとつ「ジョグで通る、手は膝につかない、次のステーションに目を向ける」。
- ランの落ち幅（Run 1→Run 8）も、初出場者は＋45.5%（4:50→6:47/km）に対し、5レース以上経験者は＋33.1%（4:19→5:35/km）。差の主因は脚の速さではなく Run 1 の自制とされる。
- 「クランプ（急失速）の壁」は2か所に集中。Run 1→Run 2（SkiErgを挟む）は初出場者の15.6%が90秒以上の急落を示し、原因はペーシングミスとされる。Run 7→Run 8（サンドバッグランジを挟む）は20.4%が90秒以上急落し、こちらは本物の脚攣り・脚の売り切れの壁。経験を積むとランジの壁は13.0%まで下がるが、Run 1 のペーシングの壁は12.3%までしか下がらず、「ペーシングの自制のほうが矯正しにくい」と結論づけられている。
- ステーション別では、初出場 Open Male の中央値でウォールボールが7:10と最長で、P90は11:40に達する唯一の種目。経験者でも5:43と最長のままで、「ウォールボールのつらさは消えない、ただ壊滅的でなくなるだけ」とされる。逆にロウイングは経験者との差がわずか16秒で、伸びしろは小さい。
- 日記での使いどころ: 10/26の第2項（Roxzoneのアーチ間違い＝2分ペナルティ）や10/25の第16項（33万件分析）とは別の、「初出場者の28万人データ」という規模の話として使える。本人は経験者だが、「Run 1 を抑える」「ランジ→Run 8 の脚を残す」は台北ソロ・名古屋ダブルス共通のテーマになる。なお本データは Open Male 初出場者が中心で、本人の Pro ダブルスにそのまま当てはまる数字ではない点に注意。

## 5. 睡眠への影響はトレーニング種目で違う: 筋トレの日は寝つきが遅く、有酸素の日は夜中の目覚めが増える（小規模研究）

- HYROX選手を対象とした2026年の研究（経験のある男性8人）では、レジスタンストレーニングの日は睡眠潜時（寝つきまでの時間）が長くなり、持久系トレーニングの日は睡眠中の覚醒（夜中に目が覚める回数・時間）が増えた。全体の睡眠の質は良好と評価されつつ、種目によって睡眠への影響の出方が違うことが、心拍の自律神経パターンとともに示された。
- 日記での使いどころ: 10/26の第6項（睡眠は「予約」、3朝ルール）の続編として、「同じトレーニングでも、筋トレの日と走る日で眠りが違う」という観察ネタに使える。本人の生活（20時就寝・0時起き）では、夜の眠りの質が翌朝の脚と直結するため、クラス中心の日とラン中心の日で翌朝の目覚めを比べる記録回にできる。ただし対象は8人の小規模研究で、HYROXの総説（プレプリント段階のレビュー）で紹介された知見であり、断定ではなく「観察してみる」切り口が適当。

## 6. ギアの考え方: 「練習用」と「レース用」の2足使い分けが賢い — 選ぶ基準はスタック30〜38mm・反発60%超・スレッドで滑らないアウトソール

- 2026年のギアガイドでは、レースシューズ選びの失敗として「純粋なランニングシューズはスレッドや荷重種目で不安定」「純粋なトレーニングシューズは8km走るには重く硬い」の両極を挙げ、目安としてヒールスタック30〜38mm、ミッドソールのエネルギー回収60%以上、ランとスレッドカーペットの両方に対応するグリップの強いアウトソールを挙げている。
- 多くの真剣な選手は「週の練習用の耐久性のある1足」と「レース用の軽いカーボン入りの1足」を使い分けており、予算が許せばこの2足体制が最も賢い、とされている。本人のローテーション（Nitro・Vomero・レース寄りの日の Dropset）と同じ発想で、「練習でレースシューズをすり減らさない」という言い回しで書ける。
- 注意点として、クッションが厚くアウトソールが滑らかなロードシューズは、スレッドのカーペットや床の変わり目でグリップ不足を露呈しやすい、との指摘もある。なお PUMA x HYROX Deviate NITRO Elite 4 そのものは10/25の第19項・10/27の第7項で既出のため、本項はシューズそのものではなく「使い分けの考え方」の切り口に限定する。
- 日記での使いどころ: 世界選手権のシューズを「カーボン入りで確定」としている本人の、購入・使い分け計画回に使える。トキさん・英一郎さんとのシューズ談義の続きとしても書ける。
